# 2024년 2학기 과제 백업

2학년 2학기 수강 과목의 과제와 자료 백업입니다.

| 폴더 | 내용 |
|---|---|
| `객체 지향/` | 객체지향 수업 정리본과 실습 입력 파일(텍스트, BMP, WAV), 채팅 분석 과제 결과 |
| `컴퓨터 구조/` | 2장 과제 |
| `신화와 현대문화/` | 교양 과목 발표 자료와 과제 |

C++ 실습 코드는 [Object-Oriented_Programming](https://github.com/Roooselina/Object-Oriented_Programming) 저장소에 있습니다.
